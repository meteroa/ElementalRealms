# 元素秘境 · 魔导对决 (Elemental Realms)

> 一款基于经典战棋卡牌名作 *Spectromancer* 深度重制的高清跨平台魔导对决卡牌游戏，融合古典奇幻油画艺术、史诗交响乐章与纯粹策略博弈。

---

## 🌟 游戏概览 (Overview)

《元素秘境 · 魔导对决》（Elemental Realms）继承了正统五系元素能量与槽位对弈机制，摒弃随机抽牌的运气成分，考验玩家在资源增长、技能连携、场面攻防上的大局观与算力。游戏采用现代技术栈对原版进行了全方位的视听重塑与移动端自适应重构。

- **核心博弈**：经典的 6 槽位棋盘攻防。生物优先攻击正对位目标，无对位目标时直击敌方英雄。
- **元素法力**：无需预制卡组与抽牌，火、水、风、土四大基础元素与流派专属第五系能量每回合自然成长，玩家根据实时能量运筹帷幄。
- **15 大魔导流派**：包含战争牧师、死灵术士、机械宗师、混沌术士、幻灵法师、兽群德鲁伊等，每个职业拥有独特的专属卡组体系与战术流派。

## ✨ 核心特色 (Key Features)

### 🗺️ 史诗战役（三大战区 · 全 23 关）
- **完整推演**：重现经典三大陆地缘战争，共计 23 场剧情 Boss 决战，决战最高导师铎拉克（Dorlak）。
- **古典沙盘大地图**：采用古典手绘羊皮纸画风重绘三大战区（Map 1, Map 2, Map 3），支持双指/鼠标自由缩放、漫游漫移与关卡镜头平滑聚焦。
- **分支推进与星门跃迁**：动态分支路线拓扑算法，通关核心要塞后激活传送星门（Portal）穿梭新大陆。

### 🏆 大师联赛与多元模式
- **大师联赛 (League)**：创建自定义角色档案，与 10~20 名各具打法风格的 AI 魔导师展开升降级大循环积分积分争霸。
- **单局对决 (Single Duel)**：自定义双方流派与 AI 难度，快速展开策略对弈。
- **P2P 局域网/互联网联机 (Multiplayer)**：基于 WebRTC (PeerJS) 构建的免服点对点对战，支持输入对战房间码秒级跨设备对决。
- **对局回放 (Replays)**：内置战局动作序列记录与回放系统。

### 🎨 典藏艺术与视听体验
- **100 款古典油画头像**：全套重绘的 100 款古典奇幻油画肖像，涵盖帝国元帅、异域领袖、虚空主宰、神圣天使与巅峰法皇。
- **全量高清卡牌与技能特效**：重绘卡面立绘，重构 50+ 种魔法粒子动效（落雷、狂熊之魂、神圣光柱、剧毒喷射等）。
- **史诗交响音乐体系**：全曲目通过 Suno 深度定制、广播级 OGG Opus 编码、0.5s 无缝交叉淡入淡出循环（Crossfade），支持 0.88x / 0.92x / 1.0x 沉稳交响慢放模式。
- **8 款电影级幻想战场**：深渊裂隙、极地雪原、丝路大漠、苍穹神坛等，支持每局真随机背景轮换。
- **竖屏与横屏双模自适应**：手机单手竖屏操作自适应，双羊皮纸常驻信息窗，无冗余遮挡。

## 🚀 快速上手 (Getting Started)

### 1. 环境准备
确保本机已安装：
- **Node.js** (推荐 v18+ 或 v20+)
- **npm** 或 **pnpm**
- （若需编译 Android 原生 APK）**JDK 17+** 与 **Android Studio / Android SDK**

### 2. 安装依赖并启动本地开发
```bash
# 进入前端核心目录
cd android

# 安装 npm 依赖
npm install

# 启动本地开发服务器
npm run dev
```
启动后在浏览器中打开 `http://localhost:5174` 即可进行游玩与调试。

### 3. 生产打包构建
```bash
# 编译 TypeScript 并生成生产 bundle 到 android/dist/
npm run build
```

### 4. 同步至 Android 原生并编译 APK
```bash
# 将构建产物同步到 Capacitor 原生 Android 容器
npx cap sync android

# 打开 Android Studio 进行调试或构建发布版 APK
npx cap open android
```
构建出的发行版 APK 亦可归档保存至 `release_apk/` 目录下。

## 📜 规则简析 (Game Rules)

1. **生命值与胜负**：初始生命值各为 60 点，率先将对方英雄生命降至 0 或以下的一方获胜（部分特殊战役关卡具有专属胜负规则）。
2. **法力增长**：每回合开始时，双方火、水、风、土四大元素各增长对应法力增长率（通常每回合 +1），第五系专属能量根据各自职业规则积蓄。
3. **出牌机制**：
   - 每回合双方只可选择**召唤一张生物**、**施放一个法术**，或者**跳过/放弃本回合（Pass）**；
   - 随从召唤后通常需要等待一回合就绪（部分生物具备登场即刻攻击的敏捷特质）。
4. **行动结算时序**：
   - 随从若具有可释放的主动特技，可在回合内主动发动；
   - 回合结束时进入自动战斗对决阶段，存活生物向正对面槽位发起攻击；若对面为空，直接削减敌方英雄生命。
