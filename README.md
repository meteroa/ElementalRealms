# 元素秘境 · 魔导对决 (Elemental Realms)

> 一款融合古典奇幻油画美学、史诗交响配乐与六槽位深度博弈的高清跨平台魔导对决卡牌游戏。

---

## 🌟 游戏概览 (Overview)

《元素秘境 · 魔导对决》（Elemental Realms）是一款专注于纯粹智谋交锋的策略卡牌对战游戏。游戏开创性地舍弃了传统集换式卡牌依赖随机抽牌的运气成分，以独特的“元素法力成长”与“六槽位攻防博弈”为核心，让胜负完全取决于玩家在资源调配、派系技能连携以及战场局势研判上的长远算力。

- **六槽位攻防博弈**：双方在各自 6 个槽位上布局生物或施展法术。战场生物优先与正对位敌军交战，当对位空虚时，攻击将直接倾泻于敌方魔导师本体。
- **动态元素能量成长**：火、水、风、土四大自然元素能量与各流派专属的第五秘能每回合自增长。所有手牌根据当前元素存量即时激活，决策深度与博弈节奏张弛有度。
- **15 大魔导流派体系**：涵盖战争牧师、死灵术士、机械宗师、混沌行者、幻灵法师、兽群德鲁伊等 15 个独立学派，各具专属卡池、数值机制与流派风格。

## ✨ 核心特色 (Key Features)

### 🗺️ 史诗战役（三大战区 · 全 23 场剧情推演）
- **宏大推演**：纵贯三大战区大陆的地缘战事，涵盖 23 场层层递进的剧情首领对决，直面最高导师铎拉克（Dorlak）的终极试炼。
- **古典沙盘大地图**：以古典羊皮纸油画质感构建全景战略大地图，全面支持触控拖拽、滚轮缩放与战役节点平滑镜头对焦。
- **分支路线与星门跃迁**：引入动态分支解锁拓扑算法，攻克大陆关键节点后开启传送星门，跨越大陆继续远征。

### 🏆 竞技赛制与多元游戏模式
- **大师联赛 (Master League)**：创建专属选手档案，与数十位打法各异的 AI 魔导师展开升降级大循环积分争霸。
- **单局对决 (Single Duel)**：自由选择对战流派与 AI 难度，随时展开一场快速智斗。
- **双人联机对战 (P2P Multiplayer)**：基于 WebRTC (PeerJS) 构建无服务端点对点网络通道，输入房间码即可秒级开启跨设备、跨局域网对决。
- **战局录像馆 (Replays)**：内置完整的对决动作序列记录与回放系统，便于复盘博弈思路。

### 🎨 典藏艺术与沉浸式视听体验
- **100 款写实古典油画头像**：原创设计涵盖帝国元帅、异域领袖、虚空主宰、神圣天使、自然女王与巅峰法皇的 100 幅高精油画肖像。
- **全量高精卡牌与魔法粒子动效**：超百张奇幻卡牌插画，配备雷霆、冰霜、兽魂冲锋、圣光净涤、腐蚀剧毒等 50+ 款高精度法术粒子视觉反馈。
- **史诗交响母带音频**：好莱坞大片级管弦交响战斗背景乐，采用广播级 Ogg Opus 编码与 0.5 秒能量守恒无缝交叉淡入淡出（Crossfade），提供 0.88x / 0.92x / 1.0x 沉稳交响慢放调节。
- **8 款电影级幻想战场**：深渊裂隙、极地雪原、丝路大漠、苍穹神坛等，支持每局随机切换场景。
- **横竖屏双模自适应**：手机端单手舒适竖屏操作，常驻双羊皮纸卡牌/战报检视窗，信息通透清晰。

## 🛠️ 技术架构 (Architecture)

| 领域 | 选用方案 | 说明 |
| :--- | :--- | :--- |
| **应用与规则引擎** | TypeScript (ESNext) + 原生响应式 DOM 引擎 | 极致轻量与高响应度，无重型框架额外运行时开销 |
| **现代构建工具** | Vite + Rolldown | 毫秒级极速热重载与模块打包 |
| **跨平台移动端容器** | Capacitor 8.5 (Android) | 原生 WebView 硬件加速与无缝 Android 容器交互 |
| **点对点通讯** | PeerJS (WebRTC DataChannel) | 免中央服务器 P2P 房间匹配与低延迟指令传输 |
| **音频管线** | Web Audio API + Ogg Opus (64kbps) | 兼顾工业级保真度与超低包体积占用（单曲仅 ~1.5MB） |

## 🚀 快速上手 (Getting Started)

### 1. 开发环境要求
- **Node.js**：v18+ 或 v20+
- **包管理工具**：npm / pnpm
- **Android 构建环境**（若需输出 APK）：JDK 17+ 与 Android Studio / Android SDK

### 2. 一键快速启动与开发 (One-Click Launch)
在项目根目录下直接双击运行脚本即可：
* **`start_dev.bat`**：一键检测环境、安装依赖、启动 Vite 服务并自动唤起浏览器打开对局（端口 5174）。
* **`start_preview.bat`**：一键执行 TypeScript 生产编译并在本地进行生产级服务预览。

亦可使用命令行手动调试：
```bash
cd android
npm install
npm run dev
```

### 3. PC 桌面端可执行程序打包 (.exe)
项目已集成标准的 Electron PC 端打包工作流：
* **`package_pc.bat`**：在根目录双击运行，将自动执行编译优化并打包生成 Windows 64位安装程序（NSIS 安装包及免安装便携版），产物输出至根目录 `release_pc/` 文件夹。
* **命令行执行**：
```bash
cd android
npm run electron:build
```

### 4. 编译输出 Android 安装包 (APK)
```bash
# 将构建产物同步至 Android 容器
npx cap sync android

# 在 Android Studio 中打开并构建 APK
npx cap open android
```

## 📜 核心规则概览 (Core Rules)

1. **生命值与目标**：对局双方初始生命值均为 60 点，率先将敌方英雄生命压制至 0 点即获胜利。
2. **法力累积**：每回合开始时，火、水、风、土四系法力自然增长，第五系专属秘能根据职业机制累积。
3. **出牌决策**：每回合玩家可在召唤随从、施展法术或休整跳过（Pass）中做出单一选择。随从进场通常在下回合就绪行动。
4. **交锋结算**：回合结算阶段，棋盘上的就绪随从自动对正对面的目标发起攻击；若对面为空槽位，随从将直击敌方英雄。
